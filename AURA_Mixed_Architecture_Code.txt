2. PYTHON CODE: MULTIMODAL IMAGE PROCESSING VIA GEMINI
────────────────────────────────────────────────────────────────────────────────
In your paper, you mentioned that the AI can process images and PDFs. Since this 
is a core academic feature, here is the exact Python implementation for how AURA 
sends images to Google Gemini 2.5 Flash for multimodal processing. 
Put this in your paper under "Sub-Section: Multimodal NLP Pipeline".

```python
import google.generativeai as genai
from PIL import Image
from flask import current_app

def analyze_student_image(image_file_path, student_prompt):
    """
    Multimodal Image Processing Engine for AURA Study Assistant.
    Utilizes Google Gemini 2.5 Flash for instantaneous OCR and contextual reasoning.
    """
    try:
        # 1. Initialize High-Speed Multimodal Vision Node
        genai.configure(api_key=current_app.config['GEMINI_API_KEY'])
        vision_model = genai.GenerativeModel('gemini-2.5-flash')
        
        # 2. Parse and validate image buffers
        student_image = Image.open(image_file_path)
        
        # 3. Securely dispatch tensor payload to external Gemini Engine
        system_instruction = (
            "You are AURA, an empathetic study bot. The student has uploaded "
            "an image of their homework, notes, or an error. Analyze the contents "
            "and assist them clearly, but proactively monitor for distressed language."
        )
        
        response = vision_model.generate_content(
            [system_instruction, student_prompt, student_image],
            generation_config=genai.GenerationConfig(
                temperature=0.4, # Low temperature for factual academic accuracy
                max_output_tokens=1000
            )
        )
        return {"status": "success", "analysis": response.text}
        
    except Exception as e:
        # Algorithmic failover trigger
        current_app.logger.error(f"[VISION AI] Payload Failure: {str(e)}")
        return {"status": "error", "analysis": "Visual processor unavailable. Falling back to text mode."}
```
