# AURA Documentation Index

This folder contains project documentation organized by purpose.

## Sections

- `deployment/` - deployment, environment, and migration guides
  - `deployment/DEPLOYMENT_GUIDE.md`
  - `deployment/ENV_FILES.md`
  - `deployment/MIGRATIONS.md`
- `project/` - project structure and architecture references
  - `project/PROJECT_STRUCTURE_GUIDE.md`
- `reports/` - audit and improvement reports
  - `reports/AUDIT_REPORT.md`
  - `reports/IMPROVEMENTS_SUMMARY.txt`
- `publications/` - publication-ready papers and related guides
  - `publications/aura/`
  - `publications/skillforge/`
- Existing technical docs:
  - `REFERENCES.md`
  - `RELEASE_CHECKLIST.md`
  - `features/`
  - `implementation/`
  - `research/`
  - `archive/`

## Why This Structure

- Keeps runtime app files at repository root clean and focused.
- Groups documents by workflow (deploy, publish, report, architecture).
- Makes onboarding faster by reducing root-level noise.
